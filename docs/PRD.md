## 1. 产品定位

**安知** 是一款面向**普通用户与大学生**的 AI 安全知识科普 Android 应用。

用户通过 AI 问答、知识卡片、分类浏览、社区交流等方式，
系统学习日常安全知识，在突发情况下获取基础应急信息。

**项目目标：** 真实可运行的项目 + GitHub 开源展示 + 实习项目经历。
**不是**只能演示的 Demo。

---

## 2. 目标用户

| 用户群 | 特征 | 核心诉求 |
|---|---|---|
| 普通用户 | 安全知识零散、缺乏体系 | 快速查到一个安全问题的答案 |
| 大学生 | 住宿舍、用电密集、易遇诈骗 | 宿舍消防/用电、反诈、校园安全 |

### 典型场景

- 学习日常安全知识
- 查询具体安全问题（「电动车能在楼道充电吗？」）
- 突发情况下获取基础应急信息
- 系统学习某个领域（消防 / 反诈 / 自然灾害）

## 3. 核心功能

### 3.1 AI 安全问答（核心）

用户输入自然语言问题，返回**结构化回答**而非纯文本。

```json
{
  "question": "宿舍发生火灾怎么办？",
  "category": "消防安全",
  "risk_level": "high",
  "answer": "...",
  "steps": ["...", "..."],
  "sources": ["..."],
  "references": [
    { "id": 3, "title": "...", "summary": "...", "category_id": 1, "risk_level": "high" }
  ],
  "warning": "..."
}
```

结构化是刚需而非装饰：`risk_level` 决定展示方式，`steps` 是可直接执行的步骤，
`warning` 在高风险时必须前置显示。

`sources` 与 `references` 都叫「来源」，但可信度完全不同，界面上分两栏：
`sources` 是**模型自己写的**公开依据，无法核实；`references` 是后端从
本项目知识库检索到的**已发布卡片**，每条带 id，点开就是原文。
前者为空是常态，后者为空也是常态（知识库没有相关内容时整栏不显示）。

### 3.2 三级风险系统

| 等级 | 示例问法 | 产品处理 |
|:--:|---|---|
| 🟢 LOW | 「灭火器有哪些种类？」 | 正常科普 |
| 🟡 MEDIUM | 「插座冒烟怎么办？」 | 强调停止操作 + 安全建议 |
| 🔴 HIGH | 「现在家里着火怎么办？」 | 简洁、立即措施优先、建议拨打紧急电话、不做长篇科普 |

**设计意图：** 高风险场景下用户可能正在慌乱中查看手机，
长篇科普会稀释关键信息，因此高风险回答必须短、准、可执行。

### 3.3 安全知识卡片

六大分类（V1.0 固定，不增不减）：

| # | 分类 | 覆盖内容 |
|:--:|---|---|
| 1 | 消防安全 | 火灾预防、灭火器、逃生、宿舍消防 |
| 2 | 用电安全 | 插座、电动车充电、短路、触电急救 |
| 3 | 交通安全 | 行人、骑行、驾驶、夜间出行 |
| 4 | 校园安全 | 宿舍、实验室、体育运动、欺凌 |
| 5 | 网络与反诈安全 | 电信诈骗、钓鱼网站、密码、隐私、AI 诈骗 |
| 6 | 自然灾害与应急 | 地震、洪水、台风、雷电、应急物资 |

**内容生产流程（强制）：** `AI 生成初稿 → 人工审核 → 发布`。
数据库 `knowledge.is_published` 默认 `false`，未经审核内容不得对外可见。
**禁止** AI 生成后自动发布高风险安全知识。

### 3.4 收藏与历史

- 收藏：知识详情页收藏按钮 → 「我的收藏」
- 历史：浏览知识自动记录 → 「浏览历史」

### 3.5 社区（V1.0 轻量）

支持：帖子列表、帖子详情、发布帖子、评论、点赞。
**不实现：** 私信、关注用户、复杂推荐、AI 审核。

### 3.6 个性化

V1.0 支持：
- 关注分类
- 首页模块显示 / 隐藏

V1.0 推荐策略：**固定推荐 + 简单用户兴趣**（收藏某分类 → 提高该分类权重），
**不实现**复杂推荐算法或机器学习。

## 5. 安全与合规要求

这是本项目的**核心差异点**，也是安全工程专业背景的体现。

### 5.1 AI 回答安全

**优先序：**

```text
生命安全优先
 ↓
避免危险操作
 ↓
给出可执行步骤
 ↓
必要时建议寻求专业帮助
 ↓
最后进行知识解释
```

**高风险禁止：**

- 鼓励用户进入危险区域
- 提供危险实验步骤
- 提供可能导致伤害的操作
- 对紧急情况进行娱乐化回答
- 信息不足时给出过度自信的判断

### 5.2 内容合规

- 知识内容必须经**人工审核**后发布
- 图片仅可使用：AI 生成 / 自行制作 / 合法授权素材 / 公共版权资源
- **禁止**使用无法确认版权的网络图片作为公开项目素材

### 5.3 密钥安全

```text
Flutter → FastAPI → .env → DeepSeek API
```

API Key 禁止出现在：Flutter 代码、GitHub 仓库、README、任何硬编码位置。

## 7. 验收标准

项目**不能**以「代码能运行」作为唯一完成标准（PROJECT_SPEC 第五十七节）。

必须同时满足：

```text
功能完成
+ 代码结构合理
+ 异常处理
+ 安全处理
+ 测试通过
+ README 完整
+ GitHub 可运行
+ APK 可以安装
```

### 必须测试的异常情况

网络断开 · API 超时 · DeepSeek 不可用 · 数据库错误 ·
用户输入为空 · 用户输入过长 · 非法请求 · 服务器异常

**不允许出现 App 直接崩溃。**
